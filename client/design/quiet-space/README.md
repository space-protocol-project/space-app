# Quiet Space — локальный вариант интерфейса

Запуск из корня репозитория:

```powershell
node client/design/quiet-space/serve.mjs
```

Открыть http://127.0.0.1:8790. Также можно открыть index.html напрямую.

Самостоятельный HTML/CSS/JS-макет, основной Flutter-клиент не изменяет. Все ресурсы локальные: логотип Space, Nunito и Nunito Sans с лицензиями OFL.

Вариант сохраняет две левые панели, тёплую графитовую тему и янтарные акценты. Переписка ограничена по ширине; дополнительные сведения открываются поверх страницы. Стекло реализовано CSS-размытием, прозрачностью и бликами, без имитации физического преломления iOS.

Работают локальная отправка (Enter; Shift+Enter для новой строки), черновики при переходах, реакции, сохранённое, поиск (Ctrl+K), создание каналов, светлая тема и настройки. Есть выбор файлов и drag&drop до десяти вложений. Сохраняются только имена и размеры файлов, их содержимое не читается и не отправляется. Сообщения и настройки сохраняются в localStorage с ключом space.quiet.v1. Черновики существуют до перезагрузки страницы. Демонстрационные собеседники не отвечают автоматически.

Подключение серверов, реальные участники, синхронизация, передача файлов и авторизация не реализованы. Панель добавления пространства явно сообщает об ограничении.

Проверено в браузере: отправка, сохранение сообщения, сохранность после перезагрузки, поиск по тексту, смена темы, экран управления. JavaScript проверен node --check. Drag&drop реализован, но перенос файла из операционной системы вручную не проверялся. Проверка узкого viewport в инструменте дала нестандартный масштаб; полноценная проверка на мобильном устройстве остаётся отдельным шагом.

Для Flutter: CSS-переменные перенести в ThemeExtension; rail/sidebar в отдельные виджеты; переписку в ListView; поле ввода в закреплённую нижнюю область; стекло в ClipRRect + BackdropFilter; панель сведений в Overlay. Уважать настройку уменьшения анимации. Реальную модель каналов и сообщений подключать через существующие контроллеры Space.

Референс поиска композиционных идей: https://dribbble.com/search/ChatGPT. Behance при просмотре недоступен; сторонние изображения не использованы.
