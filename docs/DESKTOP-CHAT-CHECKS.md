# Проверка десктопного чата после v0.4.2

Дата: 17 октября 2026 года. Локальная платформа: Windows. Эмулятор и физический Android не использовались. Личные пространства и настройки пользователя не менялись.

## Выпущенная база и найденное исправление

Совместимая пара v0.4.2 со схемой PostgreSQL 22 опубликована. Её релизные проверки: [приложение](https://github.com/space-protocol-project/space-app/actions/runs/39017978687), [runtime](https://github.com/space-protocol-project/space-server/actions/runs/39017249253).

При проверке настоящего окна обнаружено различие интерфейса: в MLS были видны маркеры `**жирного текста**`, время стояло слева под реакциями. В исходниках после v0.4.2 подключены общие MessageMarkdown, MessageBodyLayout и MessageFooter. Время теперь справа в одной нижней строке с реакциями, сверху есть отступ. Шифрование, доставка и формат сообщений не менялись. Это исправление ещё не выпущено. Новая Windows Debug-сборка собрана; при холодном запуске дерево доступности содержит форматированный заголовок MLS без Markdown-маркеров. История повторно прочитана из runtime и сохранённого тестового состояния MLS.

Первый общий параллельный прогон остановился после 92 успешных проверок без итогового результата. Он не засчитан как успешный; отдельный прогон уведомлений и последовательный прогон остальных тестов завершились штатно.

Анализатор Flutter завершился без замечаний; COG: 177 файлов, 1699 функций, максимум 15, превышений нет. Проверка контракта протокола и `git diff --check` успешны.

## Что остаётся открытым

- Полная ручная проверка мышью и клавиатурой в установленном приложении Windows: автоматизация окна получала отказ активации, затем предупреждение о пользовательском вводе. Успех чтения дерева доступности не считается успехом ввода.
- При горячем перезапуске проверочной оболочки Flutter сообщил об ошибках обновления AXTree; дерево доступности осталось от прежней вкладки, хотя снимок показал MLS. Это наблюдение режима разработки, а не доказанная ошибка холодного запуска опубликованного установщика.
- Фактическое нажатие системной карточки и полный цикл обновления установленного приложения на Windows/macOS/Linux. Релизный CI и локальные тесты не закрывают все пользовательские окружения.
- Android service, Doze, перезагрузка и системная карточка: не запускались по указанию пользователя.

Milestone v0.5 остаётся открытым для платформенной приёмки. Временные базы, ключи тестовых личностей и оболочка находятся в исключённых из Git локальных каталогах; в репозиторий не добавляются.
