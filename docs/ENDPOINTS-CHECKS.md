# Адреса пространства: локальная проверка

Реализованы этапы 1–2 ADR-035: до восьми адресов, ASCII-домены (для международных имён нужен Punycode), IPv4/IPv6, отдельные внешние и локальный порты. Список подписан ключом пространства, TLS закреплён отпечатком. Сохранённая версия препятствует откату объявления; полное согласованное восстановление всех локальных записей требует внешнего монотонного якоря.

Проверены настоящий Go runtime и временный PostgreSQL: домен localhost, IPv6 loopback, два TCP-маршрута с разными портами, отказ первого маршрута, сохранение рабочего адреса и устройства. Закрытый MLS-канал сохраняет leaf, очередь отправляется один раз, прежнее зашифрованное вложение расшифровывается. Сценарий `client/tool/home_endpoints_drill.dart` включён в `home_server_drill.dart`, который запускается существующим CI runtime. Перенос пространства проверен отдельным `home_transfer_drill.dart`: прежний TLS, история root, участники и сообщения сохранены.

Форма «Эфир» проверена на ширинах 390 и 1100, на русском, английском и китайском: резервный адрес, разные порты, отказ неверного порта, сохранение черновика при смене языка. Горячий перезапуск Windows выполнен без ошибок.

Внешняя доступность через интернет, настоящий DNS/маршрутизатор, Android и CI неопубликованных изменений пока не проверены. Опубликованный runtime v0.3.1 не поддерживает новый список: для выпуска нужна новая согласованная пара приложения и runtime. Автоматическая смена TLS-ключа не реализована; при отказе всех известных адресов нужна новая карточка, DDNS или будущий relay. Изменяющие RPC автоматически не повторяются.
