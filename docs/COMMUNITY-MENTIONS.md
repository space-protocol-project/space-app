# Упоминания и ответы в личной сводке

Дополнение приложения v0.7.25: [структурированные MLS-упоминания](MLS-MENTIONS.md).
Описанный ниже совместимый текст MLS относится к опубликованному v0.7.23;
новый формат опубликован в v0.7.25.

Выпущено в [приложении v0.7.23](https://github.com/space-protocol-project/space-app/releases/tag/v0.7.23) и [runtime v0.7.18](https://github.com/space-protocol-project/space-server/releases/tag/v0.7.18).
Нужны клиент с этим изменением и сервер с `core.community.mentions.v1`,
миграция 33→34; вместе с упоминаниями чатов итоговая схема — 35. Каталог приложения закрепляет runtime v0.7.18. [Проверки выпуска](MENTIONS-RELEASE.md).

В теме, ответе форума, публикации или комментарии ленты наберите `@` либо
нажмите кнопку упоминания. Выберите участника в поиске по имени или ID.
При одинаковых именах ID позволяет различить адресатов. Свободно набранное
`@имя` остаётся текстом. При изменении выбранного имени связь снимается;
редактирование текста до него сохраняет диапазон и ID. Не больше 10
структурированных фрагментов в сообщении. Ошибка отправки сохраняет черновик
и выбранных участников для повтора.

Подбор и отправка проверяются сервером: адресат должен иметь доступ к чтению
раздела, отправитель — право писать соответствующее содержимое. Скрытые и
закрытые родители не допускают подбор. Сервер ограничивает массовые упоминания
100 адресатами в час на личность по всем устройствам и разделам.

На «Сводке» блок «Требует внимания» показывает непросмотренные упоминания
и ответы на собственные публикации ленты. Переход ведёт к конкретному ответу
или комментарию. Конец увиденной записи снимает её упоминание отдельно:
пропущенные ранние сообщения остаются непрочитанными. Фон, неактивная вкладка
и перекрывающий диалог ничего не подтверждают. Отметка общая для устройств.
Скрытое содержимое не попадает в сводку; после восстановления непросмотренное
упоминание возвращается. При отзыве доступа сервер прекращает выдачу.

На прежнем runtime формы продолжают работать без выбора участника.
Системные уведомления, personas и общий поиск не входят в этот срез.
Android на устройстве и эмуляторе не запускается по договорённости.

Контракт и ограничения: [ADR-050](../../space-protocol/docs/adr/050-community-mentions.md).

## Дополнение: чаты

Обычные чаты используют `core.chat.mentions.v1` и схему 35. Выбранный участник
сохраняется по ID в сообщении, защищённом черновике, очереди и правках; сервер
проверяет его доступ. У сообщения есть значок `@` с именами и ID адресатов.
В MLS выбор вставляет имя в зашифрованный текст без изменения native-формата.
Подбор ограничен текущим составом группы. Отдельный серверный inbox и push
для чатов не добавляются. Подробности — [ADR-051](../../space-protocol/docs/adr/051-chat-mentions.md).

Дополнение проверено вместе с навигацией и темами: полный Flutter — 883 успешных
теста и 34 пропуска; полный Go с отдельной PostgreSQL, целевой -race, vet,
проверка модулей и достижимых уязвимостей прошли. Живая связка Dart/Connect,
Go и PostgreSQL подтвердила выбор, отправку, повтор, правку и удаление упоминания
чата. Windows release и Android debug собраны, CRC и три ABI APK проверены.
Единичная нестабильность теста очистки резервных копий Windows устранена ожиданием
видимого завершения операции файловой системы с пределом две секунды; нужное
число файлов проверяется, неудачное удаление не объявляется успешным. После
изменения прошли двадцать повторов и полный Go-прогон.
