# Примеры переписки

Снимки настоящих Flutter-виджетов приложения, тёмная тема Gruvbox.
Размер каждого PNG — 2160 × 1500. Участники, сообщения и файлы демонстрационные;
три изображения мини-галереи нарисованы локально для примера.

- [Эмодзи и реакции](chat-reactions.png).
- [Обычные файловые вложения](chat-files.png).
- [Мини-галерея изображений в сообщении](chat-gallery.png).
- [Markdown: выделение, список, цитата, ссылка и код](chat-markdown.png).
- [Избранные сообщения разных участников в чате](chat-favorites.png).
- [Список избранного с именами авторов](favorites-participants.png).

Для повторного экспорта на Windows из `client` задайте переменную
`SPACE_CHAT_SCREENSHOTS` с абсолютным путём к каталогу и запустите
`flutter test test/chat_examples_screenshots_test.dart`. В обычном CI экспорт
пропускается. Шрифт эмодзи загружается из Windows только при экспорте и в
репозиторий не копируется. Изображения и тест не входят в выпуск v0.4.1.
