# Непрочитанное в ленте

Опубликованы [приложение v0.7.21+51](https://github.com/space-protocol-project/space-app/releases/tag/v0.7.21)
и [runtime v0.7.17](https://github.com/space-protocol-project/space-server/releases/tag/v0.7.17).
Каталог клиента закрепляет этот runtime.
Сервер объявляет `core.feed.read.v1` и применяет миграцию 32→33.
Перед обновлением нужны резервная копия пространства и ключи MLS.
Возврат после миграции к runtime схемы 32 требует восстановления копии.

Публикация показывает число непрочитанных элементов: сама запись, пока она
не просмотрена, и видимые комментарии после сохранённого курсора. Тот же
счётчик отображается в блоке «Новое в сообществах» на сводке. Открытие списка,
загрузка страницы или поиск не меняют отметку. Скрытые комментарии не входят
в счётчик, скрытый родитель не выдаёт персональные сведения о чтении.
До этого среза сервер не хранил чтение ленты: старые публикации и комментарии
тоже считаются непрочитанными, пока пользователь не подтвердит их просмотр.

В обсуждении чтение подтверждается, когда пользователь дошёл до конца записи
в видимой области. Свёрнутое приложение, неактивная вкладка, перекрывающий
диалог и часть под заголовком не подтверждают чтение. Есть явная команда
«Отметить показанное прочитанным»; ещё не загруженные поздние комментарии
остаются непрочитанными.

При переходе из поиска могут быть пропущены ранние комментарии. Такой
переход автоматически подтверждает только публикацию. Вместо команды чтения
показанного предлагается «Открыть непрочитанное»: обсуждение загружается
с сохранённого курсора, без пропуска непрочитанных комментариев.

Отметка принадлежит principal и публикации и синхронизируется между его
устройствами. Курсор монотонен: запоздавшая запись или повтор не откатывают
чтение. Сервер не принимает отрицательный курсор или отметку будущего
комментария. Удаление публикации или principal удаляет отметку. Архивный
раздел допускает изменение персональной отметки при наличии права чтения;
содержимое и права публикации при этом не меняются.

Каждый запрос проверяет сессию, grant, scope, членство и read ACL. Скрытый
родитель не принимает отметку. Нельзя изменить отметку другого principal
или через ID публикации из другого раздела. Операция ограничена тремя
секундами. Страница получает персональные счётчики одним запросом; видимые
комментарии индексируются отдельно для подсчёта непрочитанного.

Клиент размещает асинхронные операции в FeedController. Смена раздела или
источника, закрытие и обнаруженный отзыв доступа отбрасывают поздние ответы.
Ошибка не рисует успешное чтение и не создаёт цикл повторов. Обновление либо
явная команда дают возможность повторить запрос. Старый сервер продолжает
работать без отметок: новый RPC не вызывается, ложный нулевой счётчик не рисуется.

Контракт: [ADR-049](../../space-protocol/docs/adr/049-feed-read.md).
Проверки: `client/test/feed_read_test.dart`,
`client/test/live/feed_server_test.dart`,
`space-server/internal/postgres/feed_read_test.go`.
В сквозном сценарии настоящий клиент подтверждает публикацию и комментарий,
проверяет список и сводку, повтор старого курсора и отказ после отзыва ACL.
PostgreSQL и runtime запускаются в отдельных тестовых каталогах на C:.

Локальные результаты 25 октября 2026: полный прогон Flutter — 863 успешных теста,
34 пропуска; две дополнительные проверки заголовка и диалога прошли отдельно.
Полный Go с настоящей PostgreSQL, целевые тесты ленты/сообществ с `-race`,
vet, проверка модулей, анализатор Dart, COG и проверка независимости ядра от
Flutter прошли. Достижимых уязвимостей Go не обнаружено. Buf lint, проверка
обратной совместимости и генерация контрактов прошли.

Windows release собран, hot reload активного debug-приложения успешен,
ошибок выполнения нет. Android debug APK собран; CRC ZIP и ELF библиотек
MLS/голоса проверены для arm64-v8a, armeabi-v7a и x86_64. При подготовке теста
миграции 32→33 удаляются и новая таблица, и новый индекс, чтобы точно
восстановить старую схему. После этой поправки общий серверный прогон прошёл.

## Выпуск 25 октября 2026 года

и [релизный CI runtime](https://github.com/space-protocol-project/space-server/actions/runs/40147670142)

проверки; Windows Setup проверен установкой поверх старой версии и перезапуском.

чтения и MLS. Общий прогон Flutter на Linux — 863 успешных теста, 36 пропусков.

SHA256SUMS.txt полностью скачаны. Размеры и SHA-256 совпали с GitHub API и
[контрольными суммами клиента](https://github.com/space-protocol-project/space-app/releases/download/v0.7.21/SHA256SUMS.txt)
и [runtime](https://github.com/space-protocol-project/space-server/releases/download/v0.7.17/SHA256SUMS.txt).
