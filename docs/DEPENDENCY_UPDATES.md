# Обновление SDK и зависимостей — 23 октября 2026

Используем свежие стабильные версии Flutter, входящего в него Dart SDK, Go и совместимых зависимостей. Перед обновлением проверяем фактический выпуск, после него синхронизируем CI, выполняем анализ, тесты, кодогенерацию и сборку. Предварительные версии требуют отдельного запроса. Это правило добавлено в `AGENTS.md`.

## SDK

| Компонент | До | После |
|---|---|---|
| Flutter stable | 3.47.7 | 3.47.8 |
| Dart из Flutter | 3.13.5 | 3.13.7 |
| Go, выбранный общей командой `go` | 1.27.0 | 1.27.3 |

SDK обновлён штатной командой `flutter upgrade`. Версии подтверждены `flutter --version`, `dart --version` и официальным [выпуском Flutter 3.47.8](https://github.com/flutter/flutter/releases/tag/3.47.8). Dart отдельно не устанавливается: используем SDK, поставляемый с выбранной версией Flutter.

В четырёх workflow закреплён Flutter 3.47.8, включая все три настройки в `desktop.yml`. В клиенте и четырёх собственных пакетах минимальная версия Dart повышена до 3.13.7; клиент дополнительно требует Flutter не ниже 3.47.8.

Go переключён штатной настройкой `GOTOOLCHAIN=go1.27.3+auto`, сохранённой через `go env -w`. `go version` подтверждает 1.27.3 и вне серверного модуля. [Описание механизма Go toolchains](https://go.dev/doc/toolchain).

В соседнем `space-server` обновлены 20 зависимостей, генератор Connect и CI. Сервер и runtime собираются с Go 1.27.3, PostgreSQL 17.11, схемой 30 и голосовым профилем 3. Подробности — в [отчёте сервера](https://github.com/space-protocol-project/space-server/blob/main/docs/DEPENDENCY_UPDATES.md).

Полный серверный прогон с `-race`, отдельной PostgreSQL и проверочным runtime: **332 теста прошли**, ошибок и пропущенных тестов нет. `go vet`, `go mod verify`, проверка упаковщика и actionlint прошли; уязвимостей вызываемого кода не обнаружено. Сквозная проверка нового сервера с клиентом прошла: TLS/Connect, владелец, приглашение, ACL, сообщение, перезапуск и сохранность данных. Системная PostgreSQL и установленное пространство не изменялись.

## Почему часть пакетов остаётся на прежней версии

После обновления `flutter pub outdated --json` показывает, что `Current`, `Upgradable` и `Resolvable` совпадают для всех оставшихся пакетов. Более новые ветки есть у девяти пакетов, но текущий совместимый граф их не допускает:

| Пакет | Используется → новый выпуск | Ограничение |
|---|---|---|
| `cross_file` | 0.3.5+5 → 0.4.0 | Последние `camera_platform_interface`, `file_selector_platform_interface` и платформенные реализации требуют ветку 0.3. |
| `desktop_drop` | 0.8.4 → 0.9.2 | Ветка 0.9 требует `cross_file ^0.4.0`, несовместимый с камерой и выбором файлов. Также меняет API и время жизни переданных файлов. |
| `screen_retriever` | 0.2.2 → 0.3.0 | Последний `window_manager 0.5.2` требует `screen_retriever ^0.2.2`; в 0.3 прежний API вынесен в устаревающий адаптер. |
| `camera_avfoundation` | 0.10.3+1 → 0.11.1 | Последняя `camera 0.12.1` требует ветку `camera_avfoundation ^0.10.2`. |
| `dbus` | 0.7.15 → 0.8.0 | Требование совместимой ветки `desktop_drop 0.8.4`. |
| `http2` | 2.3.1 → 3.1.0 | Последние `grpc 5.2.0` и `connectrpc 2.0.1` требуют ветку 2. |
| `xml` | 7.0.1 → 7.1.0 | `flutter_svg` использует `vector_graphics_compiler`, который ограничивает XML версией не выше 7.0.1. Попытка обновления проверена решателем и отклонена. |
| `material_color_utilities` | 0.13.0 → 0.13.1 | Версия закреплена самим Flutter SDK. |
| `test_api` | 0.7.12 → 0.7.15 | Ограничения `flutter_test` из SDK и `matcher`. |

`flutter_webrtc` отдельно отображается в отчёте из-за локального `dependency_override`; его текущая, разрешимая и последняя версии совпадают: 1.6.2+hotfix.4.

Разбор изменений API: [desktop_drop](https://pub.dev/packages/desktop_drop/changelog), [screen_retriever](https://pub.dev/packages/screen_retriever/changelog), [code_assets](https://pub.dev/packages/code_assets/changelog). Ограничения не обходятся принудительными переопределениями версий. Следующее обновление этих пакетов следует начинать с проверки выпусков их родительских зависимостей.

## Локальная проверка

- Анализ клиента, `space_admin_ui`, `space_api`, `space_mls_native` и `space_voice_native` прошёл без замечаний.
- `dart run build_runner build` успешно пересоздал 11 файлов Freezed; их SHA-256 совпали с результатами до обновления SDK.
- Проверка сложности: 246 файлов, 2393 функции, максимум COG 14, превышений рабочего предела 15 нет.
- Изменённые workflow прошли actionlint.
- Найдено нестабильное ожидание в тесте сохранения офлайн-правки: фиксированные 100 мс заменены ожиданием результата операции. Проверки текста и сохранности отдельного черновика сохранены. Изолированный сценарий и 23 целевых теста редактора и камеры прошли.
- Полный Flutter-прогон: 801 тест прошёл, 21 пропущен по условиям окружения.
- Все 86 нативных тестов обновлённой камеры Windows прошли. Восемь прежних проверок точного текста ошибки адаптированы к языку Windows; проверки кодов ошибок сохранены.
- Windows Release успешно собран на Flutter 3.47.8 / Dart 3.13.7: `client/build/windows/x64/runner/Release/space_client.exe`. После обновления камеры потребовалась перекомпиляция старых объектных файлов, сохранённых MSBuild; повторная сборка прошла.
- Все 9 тестов инструмента контроля сложности прошли.

`flutter doctor` подтверждает готовность Windows и Visual Studio. Android SDK локально не установлен; сборка и аппаратная проверка Android, а также сборки Linux/macOS в этот локальный проход не входят. Исторические версии SDK в старых отчётах и описаниях выпусков не переписываются.

## CI и публикация

Опубликован [runtime v0.7.14](https://github.com/space-protocol-project/space-server/releases/tag/v0.7.14). [Релизный CI](https://github.com/space-protocol-project/space-server/actions/runs/40019247321) прошёл на Windows x64, Linux x64 и macOS arm64, включая перезапуск, TLS, обновление и восстановление данных, перенос пространства и восстановление MLS. Три архива, три JSON-дескриптора и SHA256SUMS.txt полностью скачаны; размеры и SHA-256 совпали с GitHub API и контрольными суммами. Проверенные дескрипторы закреплены в `client/assets/home/runtime-manifest.json`.
