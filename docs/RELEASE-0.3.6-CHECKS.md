# Приёмка v0.3.6

Выпускается согласованная пара приложения и runtime v0.3.6. Контракт реакций — коммит space-protocol `700d439`; миграция PostgreSQL 018 добавляет реакции к существующим сообщениям. Для обычных реакций требуется обновление обеих частей.

## Состав

- Локальный каталог эмодзи, поиск и недавние; меню по удержанию/правому клику.
- Реакции обычных и закрытых каналов, синхронизация и постоянное хранение.
- Мини-галерея изображений внутри сообщения с просмотром и скачиванием.
- Упрощение Dart и обязательный предел COG 15 в CI.
- Исправление избранного Windows, автоматические аренды портов и обновления IP, systemd из предыдущих изменений.

## Локальные проверки

400 Flutter-тестов прошли, восемь штатно пропущены. Анализаторы клиента, space_admin_ui и space_mls_native без замечаний. Проверка сложности: 137 файлов, 1366 функций, максимум 15, превышений нет. Девять тестов профиля и 11 тестов подготовки выпусков прошли.

## Оставшаяся ручная приёмка

Физический Android: жесты, клавиатура, выбор/сохранение файлов. Физические роутеры, смена WAN IP и перезагрузка VPS остаются отдельными сценариями. E2EE экспериментальное: эти проверки не заменяют независимый криптографический аудит и не обеспечивают обнаружение полного согласованного отката защищённого хранилища.
