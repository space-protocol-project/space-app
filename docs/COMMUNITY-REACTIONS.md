# Реакции в форуме и ленте

В текущих исходниках реакции доступны у открытой темы и её ответов, у публикаций
ленты и комментариев. Кнопка добавления открывает общий каталог emoji. Нажатие
на выбранную реакцию снимает её. Счётчик показывает число участников,
выделение — собственную реакцию. Список чужих ID не загружается.

Для форума нужны чтение и запись. Для ленты нужны чтение и разрешение
комментирования; право публикации не требуется. Сервер проверяет права при
каждом запросе, включая повторы. В закрытой теме и архивном разделе счётчики
остаются видны, но изменять их нельзя. Скрытый объект и скрытый родитель
не раскрывают реакции даже модератору.

Реакции одного участника общие для его устройств. Они не редактируют текст,
не поднимают публикацию, не изменяют непрочитанное и не создают уведомления.
Состояние обновляется раз в десять секунд только в активном разделе.
Смена пространства, личности, разрешения устройства или раздела очищает кеш;
поздние ответы не восстанавливают состояние прежнего контекста.

При сетевом сбое «Повторить запрос» использует прежний ключ и то же действие:
потерянный ответ не вызывает двойного переключения. При конфликте ревизий
приложение загружает актуальные реакции и предлагает проверить свой выбор.
Реакции других участников не перезаписываются устаревшим запросом.

Требуется `core.community.reactions.v1` и новый сервер со схемой 38.
Старого API реакций сообществ и адаптеров нет. До 32 разных emoji на объект,
до 50 объектов в запросе чтения и до 60 новых успешных операций в минуту
на участника. Ключи повторов хранятся 14 дней.
[Контракт и транзакции](https://github.com/space-protocol-project/space-protocol/blob/main/docs/adr/055-community-reactions.md).

Избранное будет реализовано отдельным следующим срезом. Публикация нового
приложения и runtime требует отдельного запроса. Android проверяется сборкой
и автоматическими тестами, без запуска физического устройства и эмулятора.

## Локальные проверки 26 октября 2026

Полный набор Flutter: 953 теста прошли, 40 пропущены. Полный Go и `-race`
прошли с отдельной PostgreSQL; `vet`, проверка модулей и достижимых уязвимостей,
Buf и проверка OpenAPI завершились успешно.

После переноса среды на диск E: повторно прошли `flutter analyze`, 20 целевых
тестов контроллера, интерфейса и выбора emoji, а также проверка сложности:
302 файла, 2909 функций, максимальная COG 14, нарушений нет.

Настоящий Dart/Connect-клиент проверен с Go-сервером и отдельной PostgreSQL:
четыре типа содержимого, два устройства, безопасные повторы, конфликт ревизий,
перезапуск, сохранность истории, отзыв ACL и разрешения комментирования,
скрытый родитель. После сценария тестовая база остановлена.

На E: собраны Windows release и Android debug. В APK проверены CRC всех записей
и 34 ELF-библиотеки для ARMv7, ARM64 и x86_64. Устройство и эмулятор Android
не использовались. Эти проверки относятся к локальному срезу со схемой 38;
новые версии приложения и runtime ещё не опубликованы.

В нативном окне Windows на отдельном экране с тестовым API проверены снятие
реакции, повторное добавление через каталог emoji и неизменность счётчика
только для чтения. Горячий перезапуск выполнен, ошибок выполнения нет.
Это проверка интерфейса с вымышленными данными; настоящий сервер проверен
отдельным сквозным сценарием выше.
