# Совместимый выпуск поиска и сводки сообществ

25 октября 2026 года опубликованы [приложение v0.7.20+50](https://github.com/space-protocol-project/space-app/releases/tag/v0.7.20)
и [runtime v0.7.16](https://github.com/space-protocol-project/space-server/releases/tag/v0.7.16).
[Финальный релизный CI клиента](https://github.com/space-protocol-project/space-app/actions/runs/40141742605)
полностью успешен: Windows x64, Linux x64, macOS arm64, Android и сквозные
проверки с PostgreSQL. Оба выпуска подтверждены как Latest, не draft и не prerelease.

Все четыре установщика и SHA256SUMS.txt полностью скачаны. Размеры и SHA-256
совпали с GitHub API и [контрольными суммами клиента](https://github.com/space-protocol-project/space-app/releases/download/v0.7.20/SHA256SUMS.txt).
CRC APK и архитектуры MLS/голоса проверены для arm64-v8a, armeabi-v7a и x86_64.
Подпись, package ID и минимальная версия Android совпадают с v0.7.19;
versionCode увеличен с 49 до 50. Каталог внутри опубликованного APK точно
совпадает с тремя опубликованными дескрипторами runtime v0.7.16.

[Релизный CI runtime](https://github.com/space-protocol-project/space-server/actions/runs/40140240956)
прошёл на Windows, Linux и macOS. Все три архива, три JSON-дескриптора и
SHA256SUMS.txt полностью скачаны; размеры, SHA-256 и CRC ZIP проверены по API
и [контрольным суммам runtime](https://github.com/space-protocol-project/space-server/releases/download/v0.7.16/SHA256SUMS.txt).
[Опубликованный Linux-установщик](https://github.com/space-protocol-project/space-server/actions/runs/40141641166)
также прошёл проверку запуска, TLS и остановки. Runtime подтверждён как Latest,
не draft и не prerelease.

## Совместимость

| Клиент и сервер | Поведение |
| --- | --- |
| Новый клиент и runtime v0.7.15, схема 31 | Прежние функции; поиск скрыт, сводка показывает сведения о подключении и чатах и сообщает об отсутствии поддержки сообществ |
| Новый клиент и новый runtime, схема 32 | Поиск внутри раздела и персональная сводка; capabilities `core.community.search.v1` и `core.community.overview.v1` |
| Прежний клиент и новый runtime | Прежние RPC сохранены; новые экраны требуют обновления клиента |

Миграция 31→32 добавляет вычисляемые поисковые поля и GIN-индексы для форума
и ленты. Проверка обновления сохраняет прежние строки и идентичность,
проверяет поиск по старым данным и повторное открытие базы. Голосовой профиль
остаётся 3. Перед обновлением необходима резервная копия пространства и ключей
MLS. Возврат к runtime схемы 31 требует восстановления копии.

## Полученные результаты

- Полный Flutter: 856 успешных тестов, 34 пропуска; отдельно поиск и сводка —
  14 успешных тестов. Анализатор и COG без нарушений.
- Go: тесты, vet, проверка модулей и достижимых уязвимостей; PostgreSQL,
  миграция 31→32, ACL, grant и scope, скрытие родителей и целевые тесты с `-race`.
- Перенос на Windows: весь пакет `home` с настоящим runtime прошёл после
  исправления временного отказа переименования каталога.
- Windows debug собран и запущен; hot reload без ошибок выполнения.
- Android debug APK собран для трёх ABI; CRC архива и архитектуры MLS/голоса
  проверены. Проверка Android на устройстве отложена по решению пользователя.
- Сквозной `test/live/feed_server_test.dart` использует новый сервер и отдельную
  PostgreSQL. Проверяет настоящие клиентские адаптеры поиска и сводки,
  скрытие/восстановление публикации вместе с комментарием, отзыв права чтения,
  а также прежние проверки файла, идемпотентности и модерации.

Новый шаг desktop CI запускает поиск и сводку на платформах матрицы.
Серверный CI запускает расширенный сквозной тест с закреплённым клиентом.
При публикации runtime проверялся клиент `ddb84e4`; финальный CI приложения
проверил коммит `c234291` с опубликованным каталогом runtime. Тег сервера
указывает на `7fa5255`; клиент закрепляет этот коммит в `.github/space-server.ref`.

## Выполненный порядок выпуска

1. Протокол и исходники приложения и сервера сохранены отдельными коммитами;
   посторонние локальные файлы исключены. Для серверного CI закреплён новый клиент.
2. Подготовлен и опубликован runtime v0.7.16 после проверок схемы 32,
   обновления, TLS, переноса, восстановления и остановки на трёх платформах.
3. Опубликованные runtime-архивы, дескрипторы и контрольные суммы скачаны
   и проверены. Каталог клиента закрепляет эти дескрипторы v0.7.16.
4. Приложение v0.7.20+50 опубликовано после полного релизного CI и проверки
   установки runtime. Установщики и контрольные суммы скачаны и проверены.
5. TODO и документация обновлены фактическими ссылками и результатами.

Проверены релизные установщики и опубликованные архивы. Linux и macOS
проверялись на соответствующих runner CI. Android на устройстве и эмуляторе
не запускался по решению пользователя. Структурированные упоминания, отметки
чтения ленты и аппаратная приёмка голоса остаются самостоятельными задачами;
выпуск не закрывает весь milestone «Сообщества».
