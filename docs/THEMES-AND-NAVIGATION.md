# Темы и навигация пространства

Локальные изменения после v0.7.21, ещё не опубликованы.

Кнопка пространства на левой полосе открывает обзор этого пространства.
Заголовок обзора — имя пространства; отдельного пункта «Обзор» в меню
разделов больше нет. Выбор конкретного чата слева открывает этот чат.
Возврат к обзору сохраняет выбранный канал и черновики.

Настройка темы содержит три режима: «Автоматическая», «Светлая», «Тёмная».
Автоматическая тема следует системной яркости и переключается во время
работы приложения. Явно выбранные светлая и тёмная темы не зависят от
системы. Прежний сохранённый выбор переносится без изменений; новый режим
хранится отдельно, совместимый параметр `space.ui.dark` сохраняется.

В светлой теме внешний фон shell и рамка Windows используют один более
тёмный цвет `#DEDACE`. Внутренние поверхности сохраняют прежние цвета.
Тёмная тема сохраняет фон `#1D2021` и прежний цвет текста заголовка окна.
Рамка следует теме приложения, включая автоматический режим, и сохраняет
цвет при получении и потере фокуса. Новый Windows runner принимает цвета
через канал приложения; для уже запущенного runner предусмотрено применение
через DWM к HWND, возвращённому window_manager.

Проверки включают сохранение и восстановление режима, миграцию прежнего
выбора, переключение уже открытого приложения при смене системной темы,
цвета платформенного канала и навигацию к пространству и конкретному чату.
Эталоны снимков обновляются только для изменённых меню и светлого фона.

Итоговая проверка: 883 Flutter-теста прошли, 34 штатно пропущены; анализ чистый,
COG не превышает 14. Проверены снимки меню и светлой/тёмной переписки, системное
переключение открытого приложения и сохранение режима. Windows release собран
с новым нативным обработчиком цвета, Android debug собран без устройства и
эмулятора. Версии SDK — Flutter 3.47.8 stable / Dart 3.13.7; GHSA проверен
в [отдельной заметке](SECURITY-SDK.md). Публикация не выполнялась.
