# Совместимый выпуск персональных уведомлений

25 октября 2026 года. Опубликованы приложение v0.7.24+54 и runtime v0.7.19;
схема PostgreSQL 36, голосовой профиль 3. Оба выпуска Latest, без draft и prerelease.

## Runtime

[Runtime v0.7.19](https://github.com/space-protocol-project/space-server/releases/tag/v0.7.19),
коммит `572721d3881cd6d38fc181c488fb37d5fc8a4d73`.
[Полный релизный CI](https://github.com/space-protocol-project/space-server/actions/runs/40216036341)
прошёл: Windows x64, Linux x64, macOS arm64, PostgreSQL, TLS, обновление,
перенос, восстановление MLS, проверка гонок и нативное хранилище Windows.
Для серверного выпуска закреплён клиентский коммит
`b8a8c090a8660ea708f7b991134f138e244c2bfa` с реализованными уведомлениями.

Все три ZIP, три JSON-дескриптора и SHA256SUMS.txt скачаны полностью.
Размеры, SHA-256 и CRC совпали; каждый runtime-info.json содержит
schemaVersion=36, voiceRoomsVersion=3 и postgresMajor=17.
[Проверка настоящего опубликованного Linux-установщика](https://github.com/space-protocol-project/space-server/actions/runs/40217551905)
также прошла: скачивание, контрольная сумма, PostgreSQL, TLS pin,
настройка владельца и штатная остановка.

## Приложение

[Приложение v0.7.24](https://github.com/space-protocol-project/space-app/releases/tag/v0.7.24),
коммит `46c93fba3ad06df3761ef510679b093c60e071d3`.
[Полный релизный CI](https://github.com/space-protocol-project/space-app/actions/runs/40217613763)
прошёл: четыре установщика, анализ, COG, интерфейс → RPC → PostgreSQL →
второй клиент, MLS, защищённое хранилище и перенос пространства.
Проверены установка Windows поверх прежней версии и нативная очередь
активации macOS до готовности Dart. Дублирующий запуск сборок main отменён;
все обязательные задания тега выполнены успешно.

Каталог приложения и `.github/space-server.ref` закрепляют runtime v0.7.19
и его полный SHA выше. Windows EXE, macOS DMG, Linux RUN, Android APK и
SHA256SUMS.txt скачаны полностью, размеры и SHA-256 проверены.
APK прошёл CRC и проверку всех 36 ELF-библиотек трёх ABI.

Подпись APK совпадает с опубликованным v0.7.23. Сохранены package ID
`org.spaceprotocol.space_client`, minSdk 24 и ABI arm64-v8a, armeabi-v7a,
x86_64. versionName=0.7.24, versionCode=54 > 53.
Все три дескриптора внутри APK точно совпадают с публичными JSON runtime v0.7.19.

## Поведение и границы

Добавлены список непросмотренных записей по разделу, отдельная отметка
просмотра, системные карточки работающего приложения и точный переход с
повторной проверкой прав. Выбранные обращения обычного чата подтверждаются
только при фактической видимости строки. [Подробности](COMMUNITY-NOTIFICATIONS.md).

Локально прошли 916 Flutter-тестов, 35 пропущены по условиям окружения;
67 целевых проверок и настоящий сценарий Dart/Connect → Go → PostgreSQL
выполнены отдельно. Специальный новый сквозной CI-сценарий персональных
уведомлений в этот выпуск не добавлялся по выбранному порядку работ.

Перед обновлением сохраните копию пространства и ключей MLS. Откат после
миграции 35→36 требует восстановления совместимой копии.
Реальный показ и нажатие новой системной карточки на каждой ОС остаются
ручной приёмкой. Android на устройстве и эмуляторе не запускался.
Новый источник при закрытом процессе Android ещё не реализован.
Структурированные MLS-упоминания — следующий запрошенный срез;
этот выпуск сохраняет прежний зашифрованный формат MLS.
