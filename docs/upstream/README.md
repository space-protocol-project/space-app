# Материалы для flutter_secure_storage

Патч `flutter-secure-storage-atomic-write.patch` подготовлен относительно flutter_secure_storage_windows 4.2.2 из pub.dev, репозиторий upstream: https://github.com/mogol/flutter_secure_storage.

Предлагаемая тема: «Атомарная замена зашифрованной записи Windows». Проблема: нативный backend открывает действующий файл с trunc до завершения новой записи. Остановка процесса может уничтожить прежнюю защищённую запись. Патч пишет ciphertext в случайный CREATE_NEW, проверяет длину WriteFile, выполняет FlushFileBuffers и замену MoveFileExW с WRITE_THROUGH. При ошибке исходный файл сохраняется. Формат ciphertext не меняется.

Это минимальный патч нативного backend. Изменения Dart/DPAPI backend Space, partitions и тестовая аварийная остановка в него не включены; их нельзя считать исправленными этим отдельным патчем. Перед принятием upstream нужно согласовать оба backend и актуальную ветку.

Воспроизводимая проверка нативного помощника: `tools/check_secure_storage.ps1`, исходник `tools/secure_storage_atomic_test.cpp`. Проверяются отказ замены при блокировке, неизменность прежней записи, успешный повтор после освобождения и очистка временного файла после обычного отказа. Это не имитация отключения питания.

Патч и описание подготовлены локально; обращение или PR от имени пользователя не опубликованы.
