# Изменение сообщений и сохранение избранного

Дата: 15 октября 2026. Проверки для приложения v0.2.9 и сервера/runtime v0.2.5.

Меню сообщения позволяет автору редактировать текст и удалить его для всех после
подтверждения. Действия доступны только при подключении и праве записи; сервер
повторно проверяет авторство, сессию и ACL. Владельцы не изменяют чужие сообщения.
Версия защищает от перезаписи с другого устройства. Ошибка оставляет редактор
открытым с введённым текстом. Удалённый текст заменяется отметкой удаления;
порядок сообщений, время создания и курсоры сохраняются. Избранное удалённого
сообщения очищается. Для этих операций нужны новый клиент и сервер со схемой 12;
при использовании прежнего runtime эти операции недоступны. Миграция выполняется сервером.

Причина потери избранного: прямое подключение нового контроллера не загружало
сохранённую историю. Теперь она загружается до открытия сессии с прежней проверкой
идентичности и grant. Тест воспроизводил потерю после создания нового контроллера
и проходит после исправления. Он также проверяет отключение, новую серверную
сессию и запись/чтение через LocalChatHistory с новым экземпляром хранилища.
Это автоматическая модель перезапуска; ручной перезапуск пользовательского сервера
в ходе этой проверки не выполнялся.

Проверки:

- flutter analyze: без замечаний.
- flutter test: 297 успешных, 5 штатно пропущены.
- go test ./... с отдельной настоящей PostgreSQL: успешно; go vet ./...: успешно.
- ConnectRPC: реальные HTTP-вызовы UpdateContent/DeleteContent и получение обоих
  событий через Subscribe; авторство и конфликты проверены через серверные RPC.
- PostgreSQL: одновременные правки, отзыв записи, очищенный текст в истории событий,
  курсор после удаления; миграция старой истории сохраняет identity и порядок.
- Аудит приложения и сервера: production-функций с COG выше 15 нет.
- Серверный Windows-бинарный файл собран отдельно, рабочая база не изменялась.
