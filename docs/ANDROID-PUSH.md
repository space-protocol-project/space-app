# Android: уведомления от собственного runtime

Доступно в приложении v0.4.2 с runtime v0.4.2, схема PostgreSQL 22.

## Как включить

1. Добавьте пространство обычным приглашением и подтвердите доверенный ключ.
2. В настройках уведомлений выберите режим и разрешите уведомления Android.
3. Приложение автоматически зарегистрирует подключённые пространства. В системе
   появится постоянная карточка «Подключение к пространствам».
4. При необходимости разрешите фоновую работу Space в настройках батареи Android.

Firebase и отдельный сервер устанавливать не нужно. Runtime обслуживает очередь
на существующем HTTPS-порту. Компьютер с runtime должен быть включён и доступен
телефону. После сна/отключения сети доставка возобновляется при восстановлении связи.

## Приватность и переход

В фоне карточка содержит только «Space — Новое сообщение», даже если в приложении
выбран предпросмотр. Текст, имена, содержимое вложений и состояние MLS не передаются
службе доставки. Открытое приложение сохраняет существующие режимы предпросмотра.

Устройство получает отдельный ключ только для своей очереди. Другие API этот ключ
не принимают. Конверт AES-256-GCM фиксированного размера содержит указатель на
сообщение; ключ конверта независим от MLS. Сам runtime знает этот ключ, но не получает
ключи расшифровки MLS. Время активности и IP остаются метаданными.

Нажатие использует одноразовую локальную цель. Затем приложение проверяет сохранённое
пространство, текущую личность, доступ к каналу и группу MLS. Сообщение закрытого
канала загружается и расшифровывается существующим MLS-клиентом. Неизвестная группа
из уведомления автоматически не присоединяется. Отозванная цель не открывает сообщение.

## Ограничения

- Служба обслуживает до 16 пространств. Очередь объединяет активность каждого канала
  до последнего события; это не замена истории. Срок сигналов — сутки.
- До 64 карточек/целей, до 256 отметок защиты от повтора. Ключи и цели записываются
  через AtomicFile с шифрованием Android Keystore, вне резервного копирования.
- При отключении уведомлений служба останавливается; удалённое пространство
  исключается из локальной конфигурации. Отзыв устройства прекращает выдачу очереди.
- Регистрация обновляется при открытии приложения/подключении и смене маршрута.
  Через 30 дней без открытия потребуется снова открыть приложение.
- Foreground service не отменяет Doze, ограничения производителя и принудительную
  остановку в настройках Android. После принудительной остановки откройте Space.
- Если публичный адрес изменился во время закрытого приложения, может потребоваться
  открыть его для проверки нового подписанного списка адресов.
- MLS application может содержать зашифрованное действие, а не новый текст. Runtime
  не разбирает его: возможна общая карточка активности без отдельного сообщения.

## Проверки

Серверные тесты с PostgreSQL проверяют очередь/перезапуск, ack, повторную регистрацию
без потерь, недопуск capability в обычные RPC, отзыв grant, ACL, MLS membership,
исключение Commit и удаление leaf. Go и Kotlin используют общий конверт для проверки
совместимости AES-GCM и отказа при подмене/чужом ключе. Dart проверяет холодную цель,
настройки Android и разрешение MLS sequence после проверенной синхронизации.

Локальная сборка APK не доказывает приёмку Android service, Doze, загрузки системы
и нажатия реальной карточки. Эти сценарии требуют эмулятора; физическое устройство
в этой работе не используется.

Подробный контракт: `space-protocol/docs/adr/043-private-runtime-push.md`.

## Результат локальной проверки 17 октября 2026

- Flutter: 579 тестов прошли, 13 штатных пропусков; анализ без замечаний.
- Когнитивная сложность: 176 файлов, 1697 функций, максимум COG 15, превышений нет.
- Debug APK собран; повторные Gradle assembleDebug и testDebugUnitTest успешны.
- Два Kotlin-теста общего конверта runtime/Android прошли.
- Общий прогон Go с PostgreSQL успешен; окончательный push-срез повторно проверен
  с настоящей PostgreSQL, включая ограничение одной подписки на capability.
- Изолированное окно Windows собрано, горячее обновление прошло за 328 мс и окно закрыто.
- Эмулятор не запускался: локально его не было, установку образа остановили из-за
  нехватки места на C:. Частично скачанный этой задачей архив удалён.
- Приёмка Android service, Doze, загрузки и реального нажатия остаётся открытой.
  Физическое устройство не использовалось. Выпуск релиза выполняется отдельным шагом.
