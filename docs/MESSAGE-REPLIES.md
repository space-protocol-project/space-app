# Ответы на сообщения

Рабочий срез v0.5, ещё не выпущен. Для обычных каналов нужен обновлённый runtime
со схемой 20 и признаком `ordinary_replies_supported` в manifest.

Удержите сообщение на телефоне или нажмите правую кнопку мыши на компьютере и
выберите «Ответить». Исходник появится над полем ввода. Отмена ответа сохраняет
введённый текст; при переходе в другой канал выбор хранится отдельно. Предпросмотр
в отправленном сообщении позволяет перейти к исходнику, если он есть в доступной
истории. Удалённый исходник показывается заглушкой, без копии его прежнего текста.

До первого RPC текст, цель и локальные файлы сохраняются в защищённую очередь.
Ответы используют формат очереди 3: прежнее приложение отклоняет его целиком,
чтобы не отправить сообщение без ссылки. После перезапуска сохраняется тот же
ключ запроса. Поздний ответ другого пространства не очищает очередь. Квитанция
проверяется на неизменность цели даже для уже отредактированного сообщения.

При восстановлении очереди на новый grant цель входит в отпечаток исходного
запроса; совпадение ключа с другим исходником блокирует объединение. Перенос
вложений сохраняет прежние ключи и байты. Runtime без поддержки ответов
останавливает восстановленную запись до загрузки файлов и отправки сообщения.

## Отображение сообщений

Реакции находятся в нижнем ряду слева, время — справа. Между содержимым и нижним
рядом 10 логических пикселей. Компактные инициалы показывают участников каждой
реакции; подсказка содержит имя и идентификатор. Полный список открывается
стрелкой реакции. Для нового эмодзи у сообщения с реакциями доступно контекстное
меню; у сообщения без реакций остаётся кнопка добавления.

Имена обычных каналов приходят отдельно от неизменяемых идентификаторов через
`Content.participant_names`. Сервер возвращает только имена видимых авторов и
участников реакций, не каталог всех участников.

## Ответы в закрытых каналах

Меню «Ответить» и отмена без потери черновика работают также в MLS-канале.
В зашифрованном application-сообщении находится только `reply` с
`message_id` (16 байт) и `grant_id` исходного устройства. Текст и имя автора
не копируются. Предпросмотр строится по доступной локальной истории этого
канала; отсутствующий исходник показывается заглушкой. Новый участник не
получает старую историю через ответ. Открытое поле `reply_to_id` не используется.

Перед загрузкой файлов проверяется наличие исходника в локальном канале.
Rust проверяет формат ссылки и запрещает сочетание ответа с реакцией или
передачей управления. Шифртекст аутентифицирует ссылку вместе с текстом и
дескрипторами файлов. Очередь сохраняет её при перезапуске и повторном
шифровании после смены эпохи. Потерянная квитанция повторяет прежний запрос.
Зашифрованный архив истории сохраняет ссылку, но не восстанавливает ratchet.

Для MLS-ответов нужен обновлённый клиент у получателей. Прежний клиент с
запретом неизвестных полей отклоняет новый payload. Этот срез ещё не выпущен;
новая схема runtime нужна обычным ответам, MLS не требует новой миграции.

Добавление и удаление избранного находятся в контекстном меню. Отдельная кнопка
с пузырька убрана; общий список и боковые маркеры избранного сохранены.

## Проверки

- `mls_replies_test.dart`, `mls_view_test.dart`: разрешение ссылки по паре
  идентификаторов, актуальный предпросмотр, меню и отмена без потери текста.
- `mls_hostile_server_test.dart`: потеря квитанции, перезапуск, сохранение
  исходного ciphertext без дубля и импорт истории на свежем устройстве.
- Rust `closed_channel.rs`: обмен ссылкой, подмена ciphertext, запрет
  смешивания ответа с управляющими сообщениями.
- `live/mls_server_test.dart`: три клиента, ответ с файлом, недоступный исходник
  у нового leaf и повторное шифрование очереди после исключения устройства.

- `message_replies_test.dart`: потерянное подтверждение, перезапуск, ошибка записи,
  подмена цели, прежний формат, три языка и узкий экран с увеличенным текстом.
- `outbox_recovery_test.dart`: цель и байты после переноса grant, конфликт целей.
- `message_footer_test.dart`: положение времени, отступ реакций, участники,
  отсутствие отдельной кнопки избранного.
- `live/message_replies.dart`: настоящий ConnectRPC/PostgreSQL, исходный файл
  удалён после сохранения очереди; потеря подтверждения и второй перезапуск,
  сопряжённое устройство той же личности, удаление исходного сообщения.
- Go: сохранность при миграции, ACL, повтор и неизменяемая цель; имена только
  видимых участников и очистка имён прежних реакций при удалении сообщения.

Тесты не используют физическое Android-устройство.
