## Неопубликованный кандидат

Тег v0.7.22 сохранён для истории, выпуск не опубликован. Сквозной тест
Windows обнаружил отсутствующий getter chatMentionsSupported в тестовой
подмене MLS-сессии. Добавлено явное false; рабочий код приложения не менялся.
Повторный локальный сценарий обычного чата и MLS с настоящей PostgreSQL
и вторым клиентом прошёл, тестовая база остановлена. Анализатор Dart и COG
(максимум 14) прошли; горячее обновление не выявило ошибок выполнения.
Исправление и номер 0.7.23+53 вошли в новый тег; прежний тег не переносился.

Текст releaseNotes в уже опубликованных дескрипторах runtime v0.7.18
упоминает первоначальный кандидат v0.7.22. Дескрипторы и архивы сохраняются
без перезаписи. Совместимость с v0.7.23 подтверждена полным CI нового тега;
актуальная опубликованная пара фиксируется в этом отчёте и README.

## Границы проверки

Перед обновлением пространства сохраните резервную копию данных и ключей MLS.
Откат после миграций 33→34→35 требует восстановления копии подходящей схемы.
Автоматические проверки сборок и протокола не заменяют физическую приёмку
звука, камеры, телефона и системной карточки уведомления.
Физическое устройство и эмулятор Android не использовались по договорённости.
