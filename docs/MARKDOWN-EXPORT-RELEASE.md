# Совместимый выпуск Markdown, экспорта и подписок

Подготовлено приложение **v0.7.29+59**; runtime **v0.7.23** опубликован.
Выпуск приложения и проверка публичных файлов ещё выполняются. Схема PostgreSQL 41,
голосовой профиль 3. GenUI отложен и в зависимости приложения не включён.

## Возможности

- Подписки на участников и персональная хронологическая лента внутри
  пространства. Подписка не расширяет права чтения разделов.
- Ограниченный CommonMark в сообщениях, форуме и ленте. Изображения заменяются
  подписью без загрузки, HTML не исполняется, ссылки открываются по нажатию
  только после проверки. Сложный ввод отображается простым текстом.
- Экспорт собственных обычных сообщений, тем, публикаций и ответов из доступных
  неархивных разделов. Выбор раздела и периода UTC, документированный JSON
  версии 1, метаданные вложений. Чужой текст, MLS, секреты и файлы вложений
  не включаются. Это не резервная копия устройства.
- На Android JSON сохраняется через системный выбор документа без общего
  разрешения на накопитель. На настольных ОС файл сначала полностью записывается
  во временный каталог рядом с назначением.

Обновляйте сначала runtime, затем приложение. Перед миграцией 40→41 сохраните
резервную копию пространства и ключей MLS. Идентичность, история, профили,
права и отметки чтения сохраняются; возврат к схеме 40 требует восстановления
совместимой копии.

## Проверки и границы

Сборки, генерация, анализ, COG и тесты выполняются только в GitHub CI.
Локальные диски не используются для сборок; крупные установщики проверяются
на GitHub runners. Физический Android и эмулятор не используются.

Проверка интерфейса Linux использует тестовый API, настоящий файловый writer
и горячий перезапуск. Системный диалог выбора файла в этом сценарии заменён.
Настоящие права, собственное авторство, Connect/PostgreSQL и перезапуск сервера
проверяются отдельным сквозным сценарием. Компиляция Android и модульные проверки
не заменяют проверку системного диалога на телефоне.

Обзор Markdown включает исходники закреплённого рендерера и регрессионные
проверки; независимая экспертиза сторонних библиотек не заявляется.

- [Генерация, анализ и 67 целевых тестов](https://github.com/space-protocol-project/space-app/actions/runs/40404981786) прошли; сгенерированные исходники сверены с репозиторием.
- [Полный серверный прогон](https://github.com/space-protocol-project/space-server/actions/runs/40404971152) успешен: Go с проверкой гонок, vet, проверка модулей и уязвимых вызовов, анализ Flutter без замечаний, 1036 тестов / 42 штатных пропуска. Настоящий Dart/Connect → Go → PostgreSQL подтвердил собственное авторство, JSON, фильтр раздела, отзыв ACL и сохранность после перезапуска; остальные пять сценариев сообществ также прошли.
- [Проверка платформ](https://github.com/space-protocol-project/space-app/actions/runs/40404342802) полностью успешна: COG ≤15, Windows/macOS/Linux/Android, настоящий чат с PostgreSQL, нативный экспорт Linux и горячий перезапуск, обновление Windows и очередь уведомлений macOS.
- [Релизный конвейер runtime](https://github.com/space-protocol-project/space-server/actions/runs/40406370390) полностью успешен: три ОС, обновление, перенос, восстановление MLS, Go/Flutter и проверка гонок. Опубликован v0.7.23; каталог клиента получен из трёх публичных дескрипторов этого выпуска.
- [Публичный runtime](https://github.com/space-protocol-project/space-app/actions/runs/40409781309) проверен полным скачиванием в CI: размеры, SHA-256, CRC, схема 41 и распакованный размер совпали с дескрипторами. [Публичный Linux-установщик](https://github.com/space-protocol-project/space-server/actions/runs/40409785065) также прошёл проверку.
- [Установка опубликованного runtime на Windows/macOS/Linux](https://github.com/space-protocol-project/space-app/actions/runs/40409852513) успешна: скачивание по закреплённому каталогу, установка, запуск и штатный перезапуск.

[Регрессионные проверки диска и резервных копий](https://github.com/space-protocol-project/space-app/actions/runs/40409883558) прошли на трёх ОС для того же коммита приложения. Это проверки существующих возможностей, не начало v0.8.0.

[Релизный CI приложения v0.7.29](https://github.com/space-protocol-project/space-app/actions/runs/40409891076) выполняется. Нативный MLS, отрицательные сценарии и чат с PostgreSQL прошли. Публикацию приложения и финальную проверку публичной пары пока не считать завершёнными.
