# Общий поиск пространства

В исходниках следующего среза кнопка поиска в выбранном пространстве открывает
общую выдачу обычных чатов, форума и ленты. Результат показывает раздел, тип,
заголовок темы, краткий фрагмент и актуальное имя автора. Нажатие открывает
исходное сообщение, тему, ответ, публикацию или комментарий.

Нужен сервер с `core.space.search.v1`; новый RPC не входит в опубликованную
пару приложения v0.7.27 / runtime v0.7.21. Новая миграция сверх схемы 39
не требуется. Установщики этого опубликованного выпуска содержат реакции
и избранное; общий поиск готовится отдельно.

Ввод — буквальная подстрока от 1 до 256 байт UTF-8. Сервер поддерживает Unicode
и не превращает `%`, `_` или SQL в шаблоны. Результаты упорядочены по времени
создания, затем типу и ID; «Загрузить ещё» продолжает выдачу. Приложение хранит
до 500 результатов и предлагает уточнить слишком широкий запрос.

Сервер заново проверяет сессию, grant, scope, членство, блокировку и права
чтения каждого раздела на каждой странице. MLS, архив, удалённые сообщения,
скрытое содержимое и скрытые родители исключены до пагинации. Право управления
не заменяет чтение. Общие количества и сведения о недоступных разделах
не возвращаются. Запрос ограничен тремя секундами и 50 результатами.

При смене пространства, личности, grant, каталога или прав выдача очищается,
а запоздалые ответы отбрасываются. Ошибка следующей страницы также убирает
прежний текст. При переходе приложение заново загружает цель через обычный
авторизованный API; фрагмент поиска не подменяет содержимое сообщения.
Поиск не меняет непрочитанное и не подтверждает уведомления.

В заголовке диалога есть отдельный переход к поиску выбранного чата и локального
MLS. Зашифрованные сообщения не отправляются в серверный поиск. Этот режим
обходит только чаты, поэтому forum/feed-разделы не вызываются через API сообщений.

Состояние и запросы принадлежат Cubit/Freezed. Клиент проверяет размеры,
виды разделов, поля, порядок, дубли и зацикленные курсоры; сообщения копируются
и замораживаются перед сохранением в состоянии. Старый API и адаптеры не добавлены.

## Проверки

Генерация контрактов Go/Dart/OpenAPI, Freezed и переводов, форматирование,
анализ, COG, тесты и сборки выполняются в GitHub CI. Локальные сборки и тесты
остановлены после сбоя E:. Android без физического устройства и эмулятора.

[Целевой CI](https://github.com/space-protocol-project/space-app/actions/runs/40352378187)
прошёл: анализ без замечаний, 26 проверок контроллера и интерфейса, узкий экран
360 px, ширина 1280 px и увеличенный шрифт. Нативный Linux-сценарий с тестовым
API проверил ввод запроса, выбор точной цели и горячий перезапуск; ошибок
выполнения нет. Проверка COG прошла: максимум новых функций — 9, общий — 14.

[Полные платформенные сборки](https://github.com/space-protocol-project/space-app/actions/runs/40353603073)
и [серверный прогон](https://github.com/space-protocol-project/space-server/actions/runs/40352711596)
завершились успешно. Собраны Windows, macOS, Linux и Android. Анализ Flutter
без замечаний; 996 тестов прошли, 42 пропущены. Go-тесты, `-race`, `vet`,
проверка модулей и уязвимостей прошли. Проверены приватность, отзыв прав между
страницами, скрытие родителя и ограниченные курсоры. Сквозной сценарий
настоящего Dart/Connect → Go → отдельную PostgreSQL подтвердил пять типов
результатов, Unicode, неизменность истории и отметок чтения, отзыв ACL,
скрытого родителя и штатную остановку с перезапуском сервера.

[Контракт ADR-057](https://github.com/space-protocol-project/space-protocol/blob/main/docs/adr/057-space-search.md).
