# ConnectRPC: клиент и домашний HTTPS

## Выбор транспорта

Discovery нового сервера содержит `connect_endpoint: "/"`. Клиент вызывает Connect на том же origin, с Protobuf-кодеком. Самостоятельный Connect origin из ответа сервера не принимается. Неизвестное значение endpoint прекращает подключение.

Если поля нет или значение неизвестно, подключение прекращается с локализованной инструкцией обновить runtime. По решению пользователя от 14 октября обратная совместимость с прежними клиентскими транспортами не поддерживается: gRPC-клиент, его bindings, параметры подключения и выбор протоколов удалены. Внутренний gRPC-мост сервера сохраняет существующую бизнес-логику; публичный HTTPS не направляет внешние gRPC-запросы в этот сервис.

Перенесены все 37 RPC: чат, история и события, WatchChannels, участники, каналы и их права, приглашения, настройки, устройства, смена root-ключа и сопряжение. Серверный мост вызывает существующий gRPC-сервис, поэтому правила доступа и PostgreSQL остаются общими. Connect дополнительно проверяет авторизацию до декодирования HTTP-тела. Публичные процедуры одинаковы у обоих транспортов.

## Проверка HTTPS

После discovery клиент сохраняет доверенный SHA-256 отпечаток сертификата. Каждый новый TLS-сокет проверяет точный отпечаток и срок сертификата до передачи сокета HTTP-клиенту. Это относится и к сертификатам, которым доверяет системное хранилище: успешной обычной проверки TLS недостаточно при несовпадении pin.

HTTP-перенаправления отключены. Сокет разрешён только для ожидаемых схемы, хоста и порта. Локальное управление домашним сервером сохраняет его публичный origin в подписываемом transcript, используя отдельный loopback HTTP-маршрут.

Unary-вызовы имеют срок 10 секунд, подписки — 11 минут; прежняя проверка отсутствия кадров за 35 секунд сохранена. Deadline передаётся серверу и отменяет локальный запрос. Закрытие соединения отменяет активные вызовы и закрывает сокеты. Коды ошибок Connect преобразуются в прежние коды `GrpcError` для совместимости контроллеров и локализованного интерфейса.

## Проверки

- `flutter test test/rpc_connection_test.dart`: настоящий HTTPS, Protobuf/JSON, правильный и неверный pin, системно доверенный и просроченный сертификат, перенаправление, deadline, ошибки, отмена потока, обязательная поддержка Connect.
- Go-тесты транспорта: авторизация до разбора повреждённого тела для всех защищённых сервисов, Protobuf/JSON, отмена upstream и реестр 37 процедур.
- `tool/home_server_drill.dart`: кандидат домашнего runtime с PostgreSQL, владелец через локальный Connect, приглашённый участник через HTTPS Connect, отказ неверному pin, блокировка активного потока и сохранение сообщений после перезапуска. Выполняется на одноразовых runner Windows/macOS/Linux.
- Основной серверный CI выполняет тесты PostgreSQL с проверкой гонок, все тесты клиента, подписанный вход, события, отзыв, управление, recovery и pairing.

## Сложность

Проверка выполнена [treesitter_cyclomatic_complexity](https://github.com/Hecatoncheir/treesitter_cyclomatic_complexity), коммит `7b216f2344d87a910e6c1ffbd974fe60950c15ce`, Neovim 0.12.5. Режим `inline` учитывает вложенные функции вместе с внешней. Парсеры закреплены: Go `2346a3ab1bb3857b48b29d779a1ef9799a248cd7`, Dart `be07cf7118d3dba06236a3f19541685a68209934`.

Новые функции транспорта Dart: максимальная цикломатическая сложность 5, когнитивная 4. Новые функции Connect-моста Go: соответственно 3 и 2. Общая политика авторизации Go: 4 и 3. Табличные обёртки RPC имеют сложность 1/0. Это результаты новых функций; прежние большие функции сессии и запуска сервера не объявляются малосложными.

Для повторения установите парсеры, подготовьте файл со списком исходников и выполните:

```text
nvim --headless -l scripts/dump-complexity.lua dart dart-files.txt inline
nvim --headless -l scripts/dump-complexity.lua go go-files.txt inline
```

## Выпуск runtime

Использование нового клиента требует выпуска Connect-runtime и обновления закреплённого манифеста после проверки опубликованных архивов. Изменения транспорта не заменяют установленный runtime автоматически и не меняют данные, ключи или протокольную версию.
