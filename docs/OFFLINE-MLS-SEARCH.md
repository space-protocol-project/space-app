# Офлайн-поиск сохранённых MLS-сообщений — v0.5

Когда пространство недоступно, поиск предлагает «Сохранённые закрытые каналы». В выбранном закрытом канале поиск также работает без сеанса. Результат можно открыть как сохранённый текст, не подключаясь к серверу. Профиль устройства и сохранённый каталог каналов должны остаться на этом компьютере.

## Границы доступа

Чтение привязано к адресу пространства, server ID, проверенной личности и текущему grant локального профиля из зашифрованного кэша. Область MLS берётся из сохранённой привязки устройства; после смены root она может сохранять исходный MLS leaf. Произвольный архив другого устройства или пространства не открывается.

Список каналов и разрешений берётся из последнего сохранённого каталога. Без сети нельзя узнать о новом отзыве доступа на сервере. Локально известный отзыв, очистка данных, смена профиля, канала или сеанса закрывают выдачу и окно сообщения. Неприсоединённые группы, группы с revocation_pending, несовпадающим group ID и архивные/нечитаемые каналы не участвуют.

Открывается только существующее защищённое MLS-хранилище с проверкой свидетеля отката. Потеря состояния и обнаруженный откат дают отказ. Поиск не создаёт ratchet, не восстанавливает его из резервной копии, не регистрирует KeyPackage, не вызывает refresh и не отправляет RPC. В интерфейсе чтения хранилища запрещены запись/удаление; вместо криптографического движка используется заглушка с отказом на любую операцию.

Новый индекс с открытым текстом, копия архива и поисковые запросы на диск не записываются. Временная выдача находится в памяти. Предпросмотр показывает текст; файлы и их ключи через этот экран не открываются. Живой MLS-чат продолжает использовать обычную проверку и синхронизацию после подключения.

## Большие архивы

Поиск сначала сводит архив и текущие записи по ключу сообщения, сохраняя последнюю редакцию. Реакции и служебные записи не являются совпадениями. Вместо полной сортировки всех совпадений упорядоченная выборка удерживает максимум 51 Content: 50 для страницы и одну запись для признака продолжения. Разбор JSON и сведение повторов всё ещё требуют прохода по сохранённому архиву и памяти пропорционально его размеру; постоянный индекс не добавлен.

Курсор содержит границу sequence/ID и привязку к каналу, группе и запросу. Удаление или изменение граничного сообщения не обрывает следующую страницу. Новые сообщения выше границы не сдвигают продолжение. Сканирование периодически отдаёт управление интерфейсу. Между каналами сохранён прежний бюджет: максимум четыре пустые страницы либо первая непустая страница за один шаг, 200 результатов в панели.

## Проверки

`offline_mls_search_test.dart` проверяет существующий архив, отсутствие записей, запрещённый движок, неизменность системных ключей, чужой grant/адрес и свидетель отката. Проверка оболочки восстанавливает только кэш, ищет MLS-сообщение и читает его без создания сеанса, затем очищает данные и проверяет закрытие просмотра. Проверка большого архива использует 10 000 записей, удаляет границу и проверяет следующую страницу, правки, реакции и локальный отзыв.

Первый локальный замер первой страницы 10 000 записей — около 90 мс; это замер алгоритма над уже прочитанным документом, без времени системного хранилища и JSON-декодирования, не межплатформенный норматив. Оптимизация SQL-поиска больших обычных каналов и нагрузочная проверка 100 000 записей остаются отдельными задачами.

Локальная проверка: 559 тестов приложения прошли, 13 штатно пропущены; 19 целевых тестов поиска/архива также прошли. flutter analyze с прямым запуском того же серверного модуля SDK — без замечаний. COG: 173 файла, 1673 функции, максимум 15, превышений нет.

Windows release-сборка успешна. Изолированная панель с фиктивными данными запущена, горячее обновление выполнено штатной командой Flutter; ошибок в журнале запуска не наблюдалось. Для обхода зависания местного dart development-service использован --no-dds. Автоматическое форматирование генератора локализаций на время сборки отключалось, затем исходный l10n.yaml и формат сгенерированных файлов восстановлены; окончательный анализ без замечаний (9,4 секунды). Профиль пользователя, его переписка и физический Android не использовались.
