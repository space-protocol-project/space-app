# Ограниченный Markdown

Общий компонент `MessageMarkdown` отображает обычные и MLS-сообщения, текст
тем/ответов форума и публикаций/комментариев ленты. Источник остаётся текстом:
форматирование не меняет подписи, авторство, UTF-16 spans обращений или уведомления.

## Разрешённый набор

CommonMark: абзацы и переносы, заголовки, жирный/курсивный текст, обычные
и нумерованные списки, цитаты, разделители, встроенный и блочный код, ссылки.
Таблицы, task lists, зачёркивание и прочие расширения GFM выключены явно.
Имена из проверенных структурированных обращений выделяются визуально;
само форматирование не создаёт новые обращения и не выполняет действия по имени.
Кодовые блоки сохраняют буквальный текст.

## Проверка отображения

Просмотрены исходники `flutter_markdown_plus` 1.0.12: `widget.dart` создаёт
AST посредством `markdown` 7.3.1 и передаёт ссылки нашему обработчику;
`builder.dart` использует заданный `imageBuilder` вместо стандартной загрузки.
Это нативные Flutter-виджеты; HTML/WebView, JavaScript, SVG и сторонние
пользовательские рендереры не подключаются.

- `extensionSet` задан явно как CommonMark.
- Изображение любого URI заменяется ограниченной подписью, без загрузки файла,
  HTTP-запроса или декодирования изображения. Это относится и к SVG/data/file URI.
- Ссылка открывается только по нажатию во внешнем приложении. Допускаются
  абсолютные HTTP/HTTPS URI с непустым host, без userInfo, управляющих символов,
  пробелов и bidi-управления; длина до 2048 UTF-16 единиц.
- HTML остаётся буквальным текстом; разметка не получает доступ к файловой
  системе, сессии Space или ключам.
- Объём разбора ограничен 32768 UTF-16 единицами, 256 переводами строки,
  256 потенциальными разделителями, 16 вложенными квадратными скобками,
  восемью уровнями цитирования и ограничением начальных отступов.
  Ввод сверх бюджета отображается простым текстом. Проверка префиксов линейная,
  без регулярного выражения с перекрывающимися квантификаторами.

`markdown_security_test.dart` проверяет опасные ссылки, HTML/iframe/SVG,
отсутствие сетевых запросов и виджетов Image, выключенные таблицы, пределы
разбора и текст структурированного упоминания. Прежние проверки выделения,
копирования, MLS и Markdown остаются в общем CI. Это обзор реализации
и регрессионные тесты; независимая экспертиза сторонних библиотек не заявляется.
