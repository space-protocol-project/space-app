# Личное избранное форума и ленты

В текущих исходниках можно сохранить тему и ответ форума, публикацию и комментарий
ленты. Кнопка закладки находится под содержимым. В форуме список открывается
через меню действий «Избранное», в ленте — кнопкой закладок в заголовке.
Список относится к выбранному разделу и ведёт к исходному объекту, включая
нужный ответ или комментарий. Снятая отметка сразу убирает запись из списка.

Избранное личное и общее для устройств одной личности пространства. Сервер
не принимает ID владельца отметки из запроса. Для сохранения достаточно чтения:
право записи или комментирования не требуется; закрытие темы не мешает закладке.
Чужой список не выдаётся, скрытый объект и скрытый родитель не показываются.
При потере доступа все операции, включая повторы, запрещены. Переход к записи
заново проверяется обычным API форума или ленты.

Текст в избранном не копируется: список получает актуальный фрагмент и имя автора.
Отметки не меняют содержимое, реакции, непрочитанное или уведомления.
Активный интерфейс обновляется каждые десять секунд. Обновление списка сохраняет
уже загруженный объём страниц. Смена пространства, личности, разрешения устройства
или раздела очищает кеш; запоздалый ответ прежнего контекста не возвращает записи.

После сетевого сбоя повтор использует прежний ключ и то же действие. Конфликт
ревизий обновляет состояние, сохраняя новое решение другого устройства. Повторное
обновление снимает ошибку и позволяет сделать осознанный выбор заново; это
поведение исправлено также для реакций.

Нужны `core.community.favorites.v1` и сервер со схемой 39. Старого API и адаптера
нет. До 5000 активных отметок на участника, до 50 объектов в запросе состояния
и до 60 новых успешных операций в минуту; ключи повторов хранятся 14 дней.
Контракт: `space-protocol/docs/adr/056-community-favorites.md`.

## Проверки

До сбоя локального накопителя прошли 31 целевая проверка клиента, полный Flutter
(970 тестов, 40 пропусков), целевые PostgreSQL/Connect и `-race`, а также настоящий
Dart/Connect ↔ Go ↔ отдельная PostgreSQL с двумя устройствами и перезапуском.
Проверены приватность, четыре типа содержимого, повторы, ревизии, сохранность
истории, отзыв ACL, чтение без права comment и скрытый родитель. Анализ клиента
был чистым; COG — максимум 14, новые функции не выше 10.

Финальное изменение восстановления после конфликта и проверка актуального имени
автора требуют повторного полного прогона. Локальные сборки и тесты остановлены;
финальная проверка и сборки перенесены в GitHub Actions. В CI добавлены оба
сквозных сценария сообществ с перезапуском, нативный интерфейс избранного Linux
с горячим перезапуском, проверка CRC/ELF APK и сохранение отладочного APK
как артефакта. Android проверяется без физического устройства и эмулятора.

Новые версии приложения и runtime не опубликованы. Сборки ветки являются
проверочными артефактами, совместимый релиз остаётся отдельным шагом.
