# Выпуск структурированных MLS-упоминаний

Опубликовано [приложение v0.7.25+55](https://github.com/space-protocol-project/space-app/releases/tag/v0.7.25).
Совместимый runtime v0.7.19, схема 36 и голосовой профиль 3 сохранены.
Полный релизный CI завершился успешно; выпуск публичный и отмечен Latest.

Исходники тега: `e39bedacfa8df2ba9e7c88d805a3e18291d21011`.
Реализация: `9f83856`; формат и локальная приёмка описаны в
[MLS-MENTIONS.md](MLS-MENTIONS.md) и
[ADR-053](https://github.com/space-protocol-project/space-protocol/blob/main/docs/adr/053-mls-mentions.md).

[Релизный CI](https://github.com/space-protocol-project/space-app/actions/runs/40228220832)
включает установщики Windows x64, macOS ARM64, Linux x64 и подписанный APK,
новые тесты MLS-упоминаний, проверку воспроизводимости Freezed, настоящий
интерфейс чата с PostgreSQL, совместимость с сервером и нативные проверки MLS.
Параллельная сборка установщиков ветки main отменена как дубликат;
обязательные проверки тега не отменялись.

Перед тегом прошли 12 тестов подготовки выпусков, проверка описания v0.7.25,
чистый анализатор, COG (289 файлов, 2803 функции, максимум 14), 24 целевых
MLS-теста с настоящей библиотекой прежнего клиента. Полная локальная приёмка
самой реализации: 928 Flutter-тестов, 35 пропусков, 37 Rust-тестов ядра,
OpenMLS ↔ mls-rs и два сценария Dart/Connect ↔ Go ↔ PostgreSQL.

Flutter 3.47.8 / Dart 3.13.7 соответствуют текущему stable. Для всех пакетов
Current, Upgradable и Resolvable совпадают; обновления четырёх транзитивных
зависимостей ограничены совместимым графом, причины приведены в описании
функции. Каталог runtime v0.7.19 не менялся; опубликованные архивы, дескрипторы
и SHA-256 повторно проверены.

## Границы приёмки

Android на устройстве и эмуляторе не запускался. Реальное нажатие системных
карточек и доставка нового источника уведомлений при закрытом процессе
Android остаются прежними ручными задачами и не объявляются проверенными
этим выпуском. Формат v2 согласуется по подписанным листьям MLS; смешанная
группа отправляет совместимый текст v1. Откат приложения после получения v2
требует совместимой резервной копии и подходящей версии приложения.
