# Лента в Windows-приложении

24 октября 2026: снимки всей оболочки SpaceApp с настоящими сервером, PostgreSQL и отдельными тестовыми личностями. Первый локальный срез схемы 31 ещё не опубликован. Подробности и границы: [руководство ленты](../../FEED.md).

| Состояние | Широкое окно | Узкое окно Windows |
| --- | --- | --- |
| Публикации | [Снимок](feed-posts-desktop.png) | [Снимок](feed-posts-compact.png) |
| Публикация, комментарий и файлы | [Снимок](feed-discussion-desktop.png) | [Снимок](feed-discussion-compact.png) |
| Очередь жалоб отдельного модератора | [Снимок](feed-reports-desktop.png) | [Снимок](feed-reports-compact.png) |
| Скрытая публикация | [Снимок](feed-hidden-desktop.png) | [Снимок](feed-hidden-compact.png) |

Первые восемь снимков: три RPC-сессии в одном процессе Windows. В очереди используется отдельная сессия модератора, основная оболочка подключена владельцем.

Дополнительный прогон с двумя независимыми процессами и разными ключами:

- [Второе окно после повтора публикации при потере HTTP-ответа](peer-network-restored.png).
- [Второе окно после скрытия посередине скачивания](peer-hidden-mid-download.png).
- [Машиночитаемый отчёт: процессы, разрыв, полный размер и SHA-256 файла](transport-acceptance.json).

Данные тестовые, оба процесса работают на одном компьютере. HTTP-соединение оборвано loopback-посредником после ответа сервера; физический сетевой адаптер не отключался. Узкое окно не считается приёмкой физического Android.
