# Сводка пространств

В приложении v0.7.20 и runtime v0.7.16 выпущены блоки «Требует внимания»
и «Новое в сообществах». [Проверки совместимой пары](COMMUNITIES-RELEASE.md).

«Требует внимания» объединяет проблемы подключения, непрочитанные чаты,
непрочитанные ответы других участников в собственных темах форума и жалобы,
которые пользователь вправе рассматривать. Нажатие открывает пространство,
чат, нужный ответ или очередь модерации соответствующего раздела.

«Новое в сообществах» показывает свежие видимые темы и публикации доступных
пространств. У тем форума есть серверный счётчик непрочитанного. Для ленты
показываются последние публикации: отметки прочтения ленты пока отсутствуют.
Публикации, содержащие только файлы, имеют отдельную подпись.

Сводка обновляется при открытии, по общей кнопке обновления и каждые 15 секунд,
пока она видна и приложение на переднем плане. На узком экране блоки идут
друг за другом, на широком — рядом. В каждом блоке отображается до восьми
строк. Остальные действия доступны внутри пространств.

Сервер объявляет `core.community.overview.v1` и предоставляет
`CommunityOverviewService.GetCommunityOverview`. Каждый запрос проверяет
сессию, grant, членство, scope устройства и read ACL выбранного раздела.
Скрытые публикации, темы и ответы не попадают в обычную выдачу и счётчики
непрочитанного. Счётчик жалоб требует также права управления и его scope.
Запрос ограничен тремя секундами; максимум — 20 строк в каждом списке.
Для этого запроса новой миграции не требуется; текущая схема исходников — 32.

Ошибки и неподдерживаемый сервер отображаются отдельно от пустой выдачи.
Отказ в доступе очищает данные раздела; отключение пространства, смена
сеанса и закрытие сводки отбрасывают старые ответы. Сбой одного раздела
не скрывает результаты остальных. До обновления сервера остаются доступны
местные сведения о подключении и непрочитанных чатах.

Упоминания отдельным типом событий пока не поддерживаются протоколом.
Глобальный поиск, отметки чтения ленты и аппаратная приёмка Android остаются
отдельными задачами.

Серверные проверки: `space-server/internal/postgres/community_overview_test.go`.
Клиентские проверки: `client/test/dashboard_highlights_test.dart`.
Сквозная проверка настоящих адаптеров поиска и сводки, скрытия,
восстановления и отзыва read ACL: `client/test/live/feed_server_test.dart`.
Она запускается серверным CI с отдельной PostgreSQL и совместимым клиентом.

Проверка 25 октября 2026: полный прогон Flutter — 856 успешных тестов,
34 пропуска; восемь целевых тестов сводки также прошли после расширения
проверок отзыва прав и недоступных пространств. Анализатор и проверка COG
прошли. Windows debug собран и запущен, ошибок выполнения не обнаружено.
Android debug APK собран для arm64-v8a, armeabi-v7a и x86_64; проверены CRC
архива и архитектуры библиотек MLS/голоса. Проверка на устройстве не выполнялась.

На сервере прошли тесты Go, vet, проверка модулей, интеграционные тесты
PostgreSQL и целевые проверки поиска/сводки с `-race`. В ходе проверки переноса
на Windows исправлен временный отказ переименования каталога после остановки
PostgreSQL: повторяется только отказ в доступе, с ограничением времени ожидания
двумя секундами. Тесты переноса и весь пакет `home` с настоящим runtime прошли.
