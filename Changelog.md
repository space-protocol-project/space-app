# Изменения Space

Описания GitHub Releases берутся из раздела, совпадающего с тегом выпуска. Выпуски пока экспериментальные.

## Unreleased

- Все чаты сервера собраны в карточке «Чаты» с фоном и плавной рамкой при наведении. Верхний список каналов удалён; архивные чаты и недоступные обсуждения/лента/встречи скрыты в меню и поиске.
- QR восстановления создаётся из сохранённого root-ключа без подключения к серверу и показывается в блоке после ввода пароля. «Сохранить QR» сохраняет PNG; JSON остаётся доступен. В Windows выбор места сохранения выполняется внутри Space, существующий файл заменяется только после подтверждения. Если ключа восстановления нет, предлагается исходная карточка.

- Сокращены тексты основных экранов на RU/EN/中文, убраны повторные пояснения и описание будущей темы пространства. Кнопки добавления и создания вынесены в начало «Сводки». Мастер также настраивает сохранённое пространство с предварительно загруженными параметрами, сохраняя базу.

- Пароль recovery-карточки допускает любую длину и Unicode, включая пустое значение; создание проверяет только совпадение повторного ввода. Длинный ключ предварительно обрабатывается по правилам HMAC-SHA256 без изменения формата карточки.
- Восстановление в Windows выбирает PNG/JSON через диалог Space со списком папок и полным путём вместо блокирующего системного диалога. Чтение ограничено по времени; расшифровка и проверка ключей выполняются в isolate, видны этапы чтения, расшифровки, проверки сервера и подключения.

- Управление идентичностями устройства перенесено в общую страницу «Моё устройство»: выбор сохранённых ключей пространства, QR-карточка, файл, камера, сопряжение и смена ключей. Раздел удалён из меню сервера; восстановление адресуется пространству из карточки и не подменяет контроллер другого сервера.

- Начальный размер окна 1024×1024 на Windows/macOS/Linux; полосы прокрутки в диалогах скрыты, прокрутка сохранена. Одна кнопка «Выйти в эфир» открывает управление домашним сервером вместо немедленного запуска/остановки.
- В «Сводке» под добавлением пространства доступен мастер создания: название и иконка, рабочий чекбокс чата, настоящее одноразовое приглашение на 24 часа и QR, переход в управление. Обсуждения, лента и встречи показаны как будущие возможности. Существующий домашний сервер открывается без замены базы.

- «Мой сервер» доступен постоянной кнопкой слева и перечитывает сведения об обновлении при открытии. Блок «Иконка пространства» показывает необходимость обновления старого сервера. Недавние серверы подписаны и доступны для выбора только в эфире.

## v0.2.0 — 12 октября 2026 года

- Домашний сервер v0.2.0 закреплён для Windows x64, macOS arm64 и Linux x64; архивы проверяются по SHA-256. Новая установка получает этот выпуск, существующий сервер обновляется по подтверждению владельца.
- «Мой сервер → Обновить сервер»: подготовка архива до остановки, проверка совместимости и свободного места, резервная копия, закрытые миграции, проверка server ID и TLS-сертификата. Предыдущий runtime сохраняется; при сбое выполняется восстановление, изменённые данные остаются в failed-data. Журнал позволяет продолжить прерванную операцию. После обновления сервер остаётся выключенным — нажмите «Выйти в эфир».
- Исправлено зависание отключения домашнего сервера: подписки завершаются, ожидания ограничены, блокировка освобождается. Круговой индикатор запуска и остановки показывает процент этапа и прошедшее время; остаток загрузки оценивается по скорости.
- Иконки пространств: шесть стандартных вариантов и загрузка SVG/PNG в «Управление пространством». Иконка распространяется подключённым клиентам и сохраняется для отображения без подключения. Самоподписанный сертификат и доверие проверяются отдельно.
- «Управление пространством» открывается в основной области выбранного сервера. Формы привязаны к его сессии; дублирующие пункты настроек удалены. «Мой доступ и устройства» показывает доступ пользователя к выбранному пространству.
- Главная «Сводка» объединяет добавленные пространства, их каналы и ресурсы. Каждый сервер доступен отдельной квадратной кнопкой слева; меню содержит только разделы выбранного сервера. Недавние пространства перенесены в «Сводку».
- Обновлён интерфейс с существующими цветами, логотипом и шрифтами: сообщения в пузырьках с группировкой автора, единое поле ввода, компактная правая карточка с плавным появлением рамки. Компактная плотность используется постоянно.
- Enter отправляет сообщение, Shift+Enter добавляет строку; сочетания можно поменять местами в настройках приложения. Поддержан Markdown; внешние изображения не загружаются автоматически, ссылки открываются по нажатию.
- Время сообщения поступает с сервера и показывается в часовом поясе устройства. Подтверждение означает приём сервером, а не прочтение; повтор после сбоя сохраняет ключ запроса. Старые сообщения без времени показываются без него.
- В работающем Space отслеживается доступность добавленных серверов: уведомление при переходе онлайн/офлайн и значок состояния. Отключение подтверждается двумя отказами; повторные уведомления и автоматическая смена доверенных ключей исключены.
- Подключение, чат, домашний запуск и общие административные формы переведены на русский, упрощённый китайский и английский. Смена языка сохраняет черновики и несохранённые параметры; подтверждения не выполняются автоматически.
- Настройки приложения доступны отдельной кнопкой и остаются общими. Строка заголовка Windows использует цвет полосы пространств; активное окно сохраняет нейтральную рамку вместо системного акцента.
- Добавлен экспериментальный Connect-Dart 2.0.0 и сквозная проверка ConnectRPC. Основное приложение использует gRPC.

Проверка обновления и восстановления выполнена в CI на трёх ОС. Ручная проверка физической QR-камеры, домашнего роутера и установки/обновления на физических macOS/Linux остаётся открытой. DMG без подписи Apple и notarization. Автоматическое обновление самого приложения и подписанные манифесты ещё в плане; для этого выпуска установите новый пакет приложения.

## v0.1.0 — 10 октября 2026 года

- Общее приложение для общения и управления сервером: настройки, каналы и права, участники, приглашения и устройства.
- Recovery-карточки JSON/PNG, сопряжение устройств, смена ключа и QR-камера Windows.
- Автоматическое обновление каталога каналов и прав, локальные непрочитанные сообщения.
- «Выйти в эфир»: загрузка проверенного домашнего сервера, собственная PostgreSQL без Docker, сертификат по статическому IPv4 и управление из Flutter. Повторный запуск сохраняет прежний сервер; кнопка меняется на «Отключиться».
- Начальная локализация: русский, упрощённый китайский и английский; переведены оболочка, обзор, поиск и личные настройки.
- Windows Setup, macOS DMG и Linux RUN с контрольными суммами SHA-256.

Домашнему серверу нужен публичный IPv4 и проброс TCP 8443. Работа через конкретный домашний роутер требует ручной проверки. macOS/Linux требуют проверки установки и защищённого хранилища на физических системах; DMG пока без подписи Apple и notarization. Полный перевод, боты, вложения, форум, медиа, E2EE и федерация ещё в плане.
